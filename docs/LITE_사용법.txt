이 폴더에 있는 것들:
  tts-api-lite   -> 실행파일
  scripts/call_tts_api_lite.sh -> 텍스트를 보내서 음성파일(wav)을 만드는 명령
  sounds/                -> 효과음(종소리 등) 파일들, 지우지 마세요
  output/                -> 생성된 wav 파일이 여기 저장됩니다 (자동 생성)

※ 목소리 종류, 속도, 음질 등은 전부 미리 고정되어 있어서 따로 설정할 필요가
  없습니다. 텍스트 / 파일명 / 효과음번호, 이 세 가지만 입력하면 됩니다.


1. 준비
-----------------------------------------
1) 이 폴더를 원하는 위치로 옮긴다.

2) 폴더로 이동합니다.

3) 실행 권한을 줍니다.
   chmod +x tts-api-lite scripts/call_tts_api_lite.sh


2. 서버 켜기
-----------------------------------------
터미널에서 이 폴더 안에 들어간 상태로:

   ./tts-api-lite

아래처럼 나오면 정상적으로 켜진 것입니다:

   API server (lite, no config.yaml): http://0.0.0.0:9090
   output: .../output

★ 이 터미널 창은 서버가 켜져 있는 동안 계속 열어두세요.
   (창을 닫거나 Ctrl+C 를 누르면 서버가 꺼집니다)

서버를 백그라운드로 계속 켜두고 싶다면, 새 터미널 창을 열어서
아래처럼 실행하면 이 창을 닫아도 계속 켜져 있습니다:

   nohup ./tts-api-lite > server.log 2>&1 &


3. 음성 만들기 (다른 터미널 창을 새로 하나 더 엽니다)
-----------------------------------------
서버를 켠 채로, 새 터미널 창에서 같은 폴더로 이동한 뒤:

   cd ~/Desktop/lite
   ./scripts/call_tts_api_lite.sh -t "안녕하세요" -f greeting

- -t  뒤에 " "로 감싸서 원하는 텍스트를 넣습니다
- -f  뒤에 저장할 파일 이름을 넣습니다 (.wav는 자동으로 붙음)

성공하면 output/greeting.wav 파일이 생깁니다.


4. 종소리 효과음 넣기 (선택)
-----------------------------------------
-e 뒤에 숫자(0~10)를 추가하면 문장 맨 앞에 종소리가 붙습니다.
숫자를 안 쓰면 효과음 없이 만들어집니다.

   ./scripts/call_tts_api_lite.sh -t "함장님 승함하셨습니다" -f bell1 -e 1
   ./scripts/call_tts_api_lite.sh -t "함장님 승함하셨습니다" -f bell2 -e 6

  0      : 효과음 없음
  1 ~ 5  : 종소리(1x)를 그 숫자만큼 반복
  6 ~ 10 : 종소리(2x)를 (숫자-5)번 반복


5. 서버가 잘 켜져 있는지 확인하기
-----------------------------------------
   ./scripts/call_tts_api_lite.sh --health

정상이면 "status":"ok" 라고 나옵니다.


6. 서버 끄기
-----------------------------------------
- 서버를 켠 터미널 창에서 Ctrl + C
- 또는 nohup으로 백그라운드로 켰다면:
   pkill -f tts-api-lite


7. 문제가 생겼을 때
-----------------------------------------
- "address already in use" 라고 뜨면
  -> 이미 서버가 켜져 있는 것입니다. 새로 켤 필요 없이 바로 3번으로
    넘어가서 사용하면 됩니다.

- "확인되지 않은 개발자" / "손상되었기 때문에 열 수 없습니다" 뜨면
  -> 위 1-5) 항목대로 처리하세요.

- 명령을 실행했는데 "Connection refused" 같은 에러가 나면
  -> 서버(2번 항목)가 꺼져 있는 것입니다. 서버부터 켜세요.

- 결과 파일은 항상 output/ 폴더 안에 생깁니다.
